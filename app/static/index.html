단타 전략 검증기 DayTrade Strategy Lab

단타 자동매매 전략이 수수료·세금·미끄러짐을 빼고도 돈을 버는 구조인지 데이터로 확인합니다.

무엇을 하는 프로그램인가요?

한국투자증권 API로 만든 단타 프로그램은 익절 5% · 손절 2%로 설정돼 있지만, 본전보호·추적스톱·시간손절이 겹치면서 실제 평균 수익은 5%보다 훨씬 작아집니다. 이 서비스는 그 차이를 숫자로 보여 주고, 어떤 설정이 나은지 비교합니다.

  1. 손익분기 계산 — 본전이 되려면 승률이 몇 %여야 하는지
  2. 매매기록 분석 — 승률, 거래당 기대수익, 손익비(PF), 최대 낙폭, 청산사유·시간대별 성적
  3. 청산 시뮬레이션 — 분봉 데이터에 돌파 진입 + 청산 규칙을 적용해 거래를 재현
  4. 설정 비교 — 손절·익절·본전보호 조합을 한 번에 돌려 순위표 작성

파일을 올리지 않으면 합성 샘플 데이터(실제 시세 아님)로 동작합니다. 실제 주문 기능은 없으며, 결과는 투자 권유가 아닙니다.

API 문서: /docs · 분봉 CSV 예시: sample_bars.csv · 기술: Python, FastAPI, uv, AWS EC2

① 손익분기 승률 계산

익절·손절 가격에 정확히 체결된다고 가정한 이론값입니다.

② 매매기록 분석

CSV에 net_return_pct(순수익률 %) 열이 있어야 합니다. 한투 단타 프로그램의 trades_v12.csv를 그대로 올릴 수 있습니다. 선택 열: reason, time, mfe_pct, mae_pct

③ 청산 규칙 시뮬레이션

진입: 진입시간 안에서 당일 고가 돌파 + 거래량 급증 + VWAP 근처 + 시가 대비 상승률 범위를 만족한 분봉 종가. 한 봉 안의 순서를 모르므로 손절을 먼저 확인합니다(보수적). 분봉 CSV 열: code,datetime,open,high,low,close,volume

④ 설정 비교 (그리드 탐색)

입력한 손절·익절 값의 모든 조합(본전보호 켬/끔 포함)을 같은 데이터로 돌려 거래당 기대수익 순으로 정렬합니다. 과거에 잘 맞은 설정이 앞으로도 맞는다는 보장은 없습니다(과최적화 주의).
