# 단타 전략 검증기 (DayTrade Strategy Lab)

주식 단타 자동매매 전략이 **수수료·세금·미끄러짐을 반영해도 수익이 나는 구조인지** 데이터로 검증하는 FastAPI 웹 서비스입니다.

- 배포 주소: http://3.37.222.12
- API 문서(Swagger): http://3.37.222.12/docs

## 1. 만든 이유

한국투자증권 Open API로 단타 자동매매 프로그램을 만들었습니다. 설정은 **익절 5% · 손절 2%** 입니다.
숫자만 보면 승률 35%면 본전이지만, 실제로는 본전보호·추적스톱·시간손절이 먼저 작동해서
평균 수익이 5%보다 훨씬 작아집니다. 실전에 돈을 넣기 전에 **"이 설정이 정말 돈을 버는가"** 를 확인할 도구가 필요했습니다.

## 2. 주요 기능

| 기능 | 설명 | API |
|---|---|---|
| ① 손익분기 계산 | 익절·손절·비용을 넣으면 본전이 되는 최소 승률 계산 | `POST /api/breakeven` |
| ② 매매기록 분석 | 매매기록 CSV → 승률, 거래당 기대수익, 손익비(PF), 최대 낙폭(MDD), 청산사유별·시간대별 성적 | `POST /api/analyze` |
| ③ 청산 시뮬레이션 | 분봉 CSV에 돌파 진입 + 손절/익절/본전보호/추적스톱/시간손절/마감청산 규칙을 적용해 거래 재현 | `POST /api/simulate` |
| ④ 설정 비교 | 손절·익절·본전보호 조합을 모두 돌려 기대수익 순위표 작성 | `POST /api/grid` |

파일을 올리지 않으면 **합성 샘플 데이터(실제 시세 아님)** 로 동작합니다.

### 진입 규칙 (원본 프로그램의 핵심 조건을 분봉으로 단순화)
진입 시간(기본 09:15~11:00) 안에서 아래를 모두 만족한 분봉의 종가에 진입합니다.
- 당일 고가 돌파
- 직전 5개 분봉 평균 대비 거래량 1.5배 이상
- 당일 시가 대비 상승률 2~15%
- VWAP 이상, VWAP 대비 3% 이내

### 청산 규칙 (보수적 가정)
- 한 분봉 안에서 고가·저가 중 무엇이 먼저인지 모르므로 **손절을 먼저** 확인
- 갭으로 손절가 아래에서 시작하면 **시가에 청산**
- 비용: 수수료 0.015%(편도), 거래세 0.2%(매도), 미끄러짐 0.1%(편도) → 왕복 약 0.43%

## 3. 기술 스택

- Python 3.12, **FastAPI**, Uvicorn
- **uv** (가상환경·패키지·잠금 파일 관리)
- AWS **EC2** (Ubuntu 26.04, t3.micro, 서울) + **탄력적 IP**(고정 IP)
- nginx(80 → 8000 리버스 프록시) + systemd(24시간 실행, 장애 시 자동 재시작)
- Chart.js(누적 수익 곡선)

## 4. 폴더 구조

```
app/
  main.py      FastAPI 라우트 / 요청 검증
  engine.py    비용·손익분기·성과지표·시뮬레이션·그리드 엔진 (표준 라이브러리만 사용)
  sample.py    시연용 합성 분봉 데이터 생성기 (seed 고정)
  static/      대시보드 화면
tests/         단위·API 테스트 (pytest)
deploy/        systemd 서비스, nginx 설정, 서버 설치 스크립트
```

## 5. 로컬 실행

```bash
uv sync
uv run uvicorn app.main:app --reload
# http://127.0.0.1:8000
uv run pytest
```

## 6. 서버 배포 (EC2 Ubuntu)

```bash
git clone <이 저장소 주소> ~/daytrade-lab
cd ~/daytrade-lab
bash deploy/setup.sh
```
`setup.sh`가 uv 설치 → `uv sync` → systemd 서비스 등록 → nginx 연결까지 처리합니다.

## 7. CSV 형식

**매매기록** (`/api/analyze`): `net_return_pct` 필수, `reason`·`time`·`mfe_pct`·`mae_pct` 선택. 한투 단타 프로그램의 `trades_v12.csv`를 그대로 사용할 수 있습니다.

**분봉** (`/api/simulate`, `/api/grid`): `code,datetime,open,high,low,close,volume` (예시: `/api/sample/bars.csv`)

## 8. 한계와 주의

- 실제 주문 기능이 없고, 증권사 키·계좌 정보를 쓰지 않습니다.
- 분봉 단위 시뮬레이션이라 실제 체결과 차이가 있습니다.
- 과거에 좋았던 설정이 미래에도 좋다는 보장은 없습니다(과최적화 주의).
- 결과는 투자 권유가 아닙니다.
